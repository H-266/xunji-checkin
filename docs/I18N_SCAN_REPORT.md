- 用户可见中文源字符串：**628 条唯一**（含中文日期分支与语言自名）。
- 已写入四语翻译表：**591 条 × en/ja/fr/es = 2364 条译文**，位于 `lib/core/app_strings_generated.dart`。
- 占位符校验：所有含 `${...}` / `$var` 的 116 条源串逐条比对，**0 处丢失或改名**。
