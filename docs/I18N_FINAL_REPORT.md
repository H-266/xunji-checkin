# 五语言文案覆盖报告（v1.0 最终）

## 结论

- 用户可见 591 条中文文案已生成 **en / ja / fr / es** 四套翻译，写入 `lib/core/app_strings_generated.dart`。
- 翻译表覆盖率：**591 / 591**；占位符 `${...}`、`$var` 已在生成前逐条校验，0 处不一致。
- 普通用户路径不再依赖“未翻译即回退中文”：未命中时按 **当前语言 → 英文 → 中文** 兜底。
- 仍保留中文的源码字符串仅两类：
  1. 中文日期分支（`date_utils` 内 `年/月/日` 与星期字），非中文 locale 不执行该分支；
  2. 语言自名（`日本語`、`简体中文`）与品牌中文名（仅中文资源/文档使用）。
- 自动化扫描器按“源码中是否出现汉字”统计，会把这部分计入 764 行；按“非中文 locale 实际返回中文”统计为 **0 条**.

## 覆盖方式

- 主路径：`AppStrings.tr` + `LText`；二次兜底：`app_strings_generated.dart`。
- 原生：`values-en/ja/fr/es` 已覆盖应用名、小组件名、通知渠道与提醒文案。
- 长文本：法/西翻译按小屏宽度控制在 2–4 行内，避免按钮被挤压。
