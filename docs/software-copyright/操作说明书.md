# 循记打卡 软件操作说明书（v1.0.0）

## 1. 软件概述

循记打卡是一款纯本地运行的 Android 打卡与待办工具。软件不联网、不注册账号，使用 SQLite 保存任务、打卡、备注、标签与设置，并以“全局热力图”作为核心统计视图。

- 软件名称：循记打卡
- 版本号：1.0.0
- 包名：`com.xunji.checkin`
- 运行平台：Android 8.0 及以上
- 开发框架：Flutter 3.47.9 / Dart 3.13.7
- 数据存储：本机私有 SQLite（`xunji_checkin.db`）

## 2. 首次启动

1. 安装 APK 后点击图标启动。
2. 阅读隐私说明，勾选“我已阅读并同意《隐私政策》”。
3. 点击“同意并继续”。
4. 进入四步新手引导；可点“下一步”逐步了解，也可点“跳过”直接进入首页。

## 3. 今日打卡

1. 点击右下角“新建任务”。
2. 输入任务名称，选择“打卡任务”或“临时待办”。
3. 打卡任务可设置重复周期：每日、每周 N 天、自定义星期、间隔天数、每月日期、每年日期。
4. 点击任务左侧圆形复选框完成打卡；再次点击取消。
5. 长按任务可编辑、置顶、补卡、写备注、归档。
6. 左滑归档，右滑编辑。
7. 临时待办完成后从今日列表消失，但历史记录仍保留。
8. 下拉今日页可打开搜索；右上角菜单进入批量管理。

## 4. 热力统计

1. 底部“热力”进入月视图。
2. 每个格子代表一天，颜色由当天完成率决定；100% 时高亮描边。
3. 点击某一天查看完成数、任务明细、备注和打卡时间。
4. 左右滑动切换月份；顶部可切换标签筛选。
5. 点击顶部“年度热力图”查看全年；点击月份可回到对应月视图。
6. 点击统计图标进入高级统计：环比、Top5、标签/类型/时段/周期表现。
7. 分享菜单可保存本月/全年长图。

## 5. 桌面小组件

1. 底部“小组件”查看任务卡片和热力卡片预览。
2. 选择尺寸后点“添加到桌面”。
3. 若系统未弹出添加面板，长按桌面 → 添加小部件 → 搜索“循记打卡”手动添加。
4. 组件只展示，点击卡片打开 App 对应页面；打卡在 App 内完成。

## 6. 设置

- 外观：热力主色、六套主题预设、深浅色、字体大小、界面语言。
- 数据：JSON 导入/导出、CSV 导出、自动备份、标签管理、归档回收站。
- 保活：电池优化状态、系统电池设置、自启动设置、各品牌保活提示。
- 通用：自动归档临时待办、隐私政策、错误日志、使用教程。
- 关于：版本号、开源协议、隐私政策入口。

## 7. 数据安全

1. 所有数据仅保存在应用私有目录。
2. 导出/导入/自动备份均通过 Android SAF 系统选择器完成，应用不申请存储权限。
3. 卸载应用会删除私有数据库；请在卸载前导出备份。
