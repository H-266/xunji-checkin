# 软件著作权申请材料模板

本目录仅整理材料模板，不包含任何代办服务。所有材料可直接用于中国版权保护中心官方免费申请，具体以受理系统最新要求为准。

## 建议提交内容

| 材料 | 文件 | 说明 |
| --- | --- | --- |
| 软件名称 | 本文档 | 循记打卡 |
| 版本号 | 本文档 | V1.0.0 |
| 功能说明 | `操作说明书.md` | 操作步骤、模块说明 |
| 源程序 | 自行从仓库导出 | 前 30 页 + 后 30 页，共 60 页 |
| 文档 | `操作说明书.md` 导出 PDF | 建议 30 页以上，含截图 |
| 申请表 | 版权中心系统生成 | 开发者/著作权人信息自行填写 |

## 源程序页整理规范

1. 仅提交源代码，不提交图片、二进制、构建产物。
2. 每页不少于 50 行（不足 50 行的末页除外），A4 纸单面打印。
3. 前 30 页从程序入口开始（`lib/main.dart`），后 30 页取仓库末尾核心文件。
4. 页眉标注软件名称、版本号；页脚连续页码。
5. 删除空行过多的排版；不要插入与程序无关的注释。
6. 建议包含：`lib/main.dart`、`lib/data/app_database.dart`、`lib/providers/task_provider.dart`、`lib/core/stats.dart`、`lib/screens/today_screen.dart`、`lib/screens/heatmap_screen.dart`、`android/.../MainActivity.kt`、`WidgetRenderer.kt`。

## 建议申请的软件分类

- 应用软件 / 效率工具 / 生活辅助
- 软件用途：本地打卡、习惯记录、完成率热力图统计、桌面小组件展示。

## 注意事项

- 申请表中的开发完成日期、首次发表日期、著作权人信息需由申请人如实填写。
- 代码中如含第三方开源库，按其许可证保留版权声明；本项目主体代码以 MIT 协议开源。
- 操作说明书中的截图请使用自己设备的真实截图，避免使用含个人信息的内容。
